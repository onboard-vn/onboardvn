# Branding

Ảnh gốc chất lượng cao. Bản tối ưu cho web nằm ở `apps/web/public/brand/` và `apps/web/app/` (favicon, icon, apple-icon, opengraph-image).

| File                       | Dùng cho                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------ |
| `logo-horizontal.png`      | Logo ngang, nền trong suốt, cho nền sáng                                             |
| `logo-horizontal-dark.png` | Logo ngang cho nền tối                                                               |
| `logo-mark.png`            | Biểu tượng, nền trong suốt (favicon, icon)                                           |
| `logo-mark-cream.png`      | Biểu tượng trên nền kem (avatar GitHub org, apple-icon)                              |
| `hero-illustration.png`    | Minh họa trang chủ                                                                   |
| `cover-banner.png`         | Ảnh bìa 3:1 (fanpage/social) — có in `onboardvn.com`, chỉ dùng sau khi sở hữu domain |
| `poster.png`               | Poster 4:3 — có in `onboardvn.com`, như trên                                         |
